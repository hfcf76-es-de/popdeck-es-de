# Popdeck (https://github.com/hfcf76-es-de), theme for [ES-DE](https://es-de.org/)

The theme consists of a carousel of icons positioned above a bar (containing information about the system or the game), at the bottom of the screen, with a video preview window in the middle. Nothing is positioned in the middle of the screen, so that the background art really stands out.


## Configuration Options

- `Theme Aspect Ratios`: 16:9, 16:10, 19.5:10 and 4:3


- `Theme Variants`:

Dark:
Dark theme with dark gray tones and white fonts

Light:
Light theme with light gray tones and black fonts


- `Theme Color Schemes:`

Square Icons:
Items in the carousel are square icons

Rounded Icons: 
Items in the carousel are square icons with slightly rounded corner

Circle Icons:
Items in the carousel are circles
